# Machine Learning — Mushroom Classification

Mushroom data exploration and classification experiments using scikit-learn and UCI data access.

**Portfolio:** [Carl Renz Colico](https://github.com/renzkie8) · **Year:** Unconfirmed

## Methodology

Fetch UCI mushroom data, encode categorical features, split data and test classification algorithms with visual exploration.

## Results and limitations

The original Python script and notebook are preserved. The script fetches UCI dataset 848 through ucimlrepo; supplied raw CSVs are excluded. The mixed archive also held other coursework, which is routed to its own repositories.

This upload documents the supplied submission. Experiments, model training, graphical interfaces and external services were not fully rerun during portfolio preparation. See VALIDATION.md for checks actually performed.

## Getting started

Open the notebook with JupyterLab or Jupyter Notebook. Install the imports used by its cells in a dedicated environment, obtain the inputs described in DATA.md, check local file paths, and run cells in order. GPU/cloud and historical library assumptions in the source may need adjustment.
